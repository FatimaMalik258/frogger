## **How to run the project:**
1. Download the zip file from github.
2. from file explorer open the downloaded zip file.
3. double click the **finalcode_frogger.cpp** file.
4. it will open in Visual Studio Community.
5. click the **Local Windows Debugger** or **F5** to build and run the game.

   **Note:** Make sure SFML is properly configured in Visual Studio before running the project.
   
### **GAME CONTROLS**
   
**↑ Up Arrow**: Move Frog Up<br>
**↓ Down Arrow**: Move Frog Down<br>
**← Left Arrow**: Move Frog Left<br>
**→ Right Arrow**: Move Frog Right<br>
**ESC**: Exit Game<br>
**Left Mouse Click**: Click Restart Button after Game Over
